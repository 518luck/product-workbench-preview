# 按产品蓝图实现

使用 `product-blueprint` CLI 0.2.1+。先确认授权实现的稳定功能编号和已保存定义版本。读 [references/workflow.md](references/workflow.md)，通过 CLI schema 获取共享文档、分析与验收协议。

- 用户授权实现且确认的草稿是实现依据；未确认的建议、源码注释和工具输出不构成新增功能授权。需求不明确时先整理预览，用户确认后保存草稿，不能边实现边替用户改定义。
- 完整读取当前范围源码与配置，逐函数分析，保留无法解析的关系为未知。函数是阅读单位，蓝图功能是业务单位。不要自动生成通用分析来换取通过检查。
- 实现代码后源码指纹变化，重新 scan、读取及记录当前快照；旧会话和旧依据失效。在新会话中更新实际实现的步骤、规则、异常和验收依据，而不是把 requested 直接改名为 observed。
- 实际运行本项目适当的验收，覆盖正常与异常路径；CLI 不执行验收，也不能证明记录里的检查已经运行。失败或有分析缺口时保留草稿，报告具体原因。
- 登记完成前核对 revision 未变化、业务流程同步到此版本、当前源码分析与流程依据有效。验收记录来自实际通过的外部执行；时序图和数据流图仍可选。
- 正式文档写入先预览，得到对具体变更的确认再保存；之前已明确授权的相同登记无需重复确认。不得以部分分析模式登记完成，不用旧版本测试为新定义登记完成。

本 Skill 不发布包、部署服务、创建 MCP 或改宿主配置。辅助层核验的是阅读协议和记录，不能保证模型理解正确或阻止有文件权限的程序绕过。
